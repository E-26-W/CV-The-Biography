CV Website
==========
Open index.html in a browser.

Features:
- Preserves the supplied Arabic and English CV designs as exact visual page images.
- Switches between Arabic and English.
- Download the corresponding original PDF.
- Print the CV.
- Responsive scaling for desktop and mobile.

Files:
- index.html, style.css, script.js
- cv-ar.png, cv-en.png
- cv-ar.pdf, cv-en.pdf
